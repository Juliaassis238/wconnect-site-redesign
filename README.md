# WConnect — Site institucional

Página institucional da WConnect com foco em inteligência artificial, software sob medida, automação e soluções digitais.

## Conteúdo

O projeto é uma página HTML única com CSS e JavaScript incorporados no próprio arquivo. A página inclui navegação responsiva, hero section, soluções, serviços, vantagens, processo, indicadores, clientes, blog, contato e interações visuais.

## Execução local

Abra o arquivo `index.html` diretamente no navegador ou execute um servidor HTTP local:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Observações

As fontes são carregadas pelo Google Fonts. Os demais recursos podem depender de URLs externas utilizadas pelo código original.

Este repositório foi criado a partir do código enviado pelo proprietário do projeto.
